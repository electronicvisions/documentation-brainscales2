class pygrenade_vx.network.abstract.multicompartment.morphology_builder.MorphologyBuilder(neuron_type=<class 'pygrenade_vx.network.abstract.multicompartment.neuron.Neuron'>)

Bases: object

Construct a multicompartment neuron class.

Parameters

neuron_type – Base class from which the neuron created in the builder

derives.

Compartments can be added and interconnected. The builder supports cloning branches of interconnected compartments and connecting different branches to one neuron. The created neuron must be fully connnected and acyclic.

__init__(neuron_type=<class 'pygrenade_vx.network.abstract.multicompartment.neuron.Neuron'>)
