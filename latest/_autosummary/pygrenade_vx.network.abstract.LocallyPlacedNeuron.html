get_input_ports(self: _pygrenade_vx_network_abstract.LocallyPlacedNeuron) → list[pygrenade_common.Vertex.Port]

Get input ports. The LocallyPlacedNeuron features one input port of synaptic input to the neuron (port index 0). Its channels are formed by the receptors (dimension 1) per compartment (dimension 0) on the neuron.

get_output_ports(self: _pygrenade_vx_network_abstract.LocallyPlacedNeuron) → list[pygrenade_common.Vertex.Port]

Get output ports. The LocallyPlacedNeuron features one output port of spikes from the neuron (port index 0), where the channels are the compartments, and one output port of an analog value to read out (port index 1), where the channels are the atomic neuron circuits (dimension 1) per compartment (dimension 0).
